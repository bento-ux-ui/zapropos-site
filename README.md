# ZAPROPOS — site public

Microsite statique indépendant du moteur de production vidéo.

- Hébergement : Cloudflare Pages, déploiement depuis `main`.
- Domaine : `https://zapropos.fr` (raccordement DNS en cours).
- Site temporaire : `https://zapropos-site.pages.dev`.
- Page unique : accueil, projet, fonctionnement, confidentialité, conditions et contact.
- Adresse directe de confidentialité : `/confidentialite/` (réécriture Cloudflare vers `index.html`).

Aucun identifiant OAuth, jeton, secret ou fichier du moteur de production ne doit être ajouté à ce dépôt.
